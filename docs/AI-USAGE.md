Файл ведём с первого дня — восстанавливать по памяти на седьмой заметно хуже.

Формат строки: дата — кто — где — что именно.

| Дата | Участник | Этап / часть | Как использовался |
|---|---|---|---|
| 2026-08-06 | (бэкенд) | Процесс: `CLAUDE.md`/`AGENTS.md`, `.golangci.yaml`, `docs/ARCHITECTURE.md`, `docs/DECISIONS.md`, CI, `.claude/*` | Claude Code — предложил и скорректировал сценарий разработки после разбора кейса, макетов и уже написанного кода на `feat/auth`/`feat/pet-service`; решения по стеку и архитектуре принимались и правились человеком, не принимались вслепую |

## Инструменты

- Claude Code — сопровождение процесса разработки бэкенда (сценарии, архитектура,
  тулинг), ревью PR (`.github/workflows/claude-review.yml`, требует установки GitHub App
  и секрета — см. `docs/DECISIONS.md` → «не сделанная работа»)
- (дополнить: что использует фронт)
