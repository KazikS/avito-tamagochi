# Использование ИИ

Кейс требует указать, на каких этапах и как использовались нейросети.

**Это не ежедневный журнал.** Мы пробовали формулировку «ведём с первого дня» и честно
признали, что четыре человека под дедлайн его вести не будут. Поэтому источник — история
git, а этот файл собирается один раз, в день 6, перед защитой.

Что делает историю пригодной для восстановления (соблюдаем по ходу, а не в конце):

- Conventional Commits и осмысленные описания PR.
- Коммиты, сделанные с помощью ИИ, несут `Co-Authored-By` соответствующего инструмента.
- Если ИИ повлиял на решение, а не только на код, — строка «почему» в
  `docs/DECISIONS.md` пишется человеком и своими словами.

Сборка черновика в день 6:

```bash
git log --pretty='%ad %an %s' --date=short --no-merges | sort
git log --grep='Co-Authored-By' --pretty='%ad %an %s' --date=short
```
