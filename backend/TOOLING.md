# Инструменты — что каждый предотвращает

Не список «модного стека». Каждый пункт закрывает конкретный риск, который иначе ловится
на ревью (медленно) или на защите (поздно).

**Статус важнее описания.** Файл описывает, как пользоваться инструментом, а не обещает,
что он будет. Список ниже — единственное место, где написано, что реально подключено;
инструмент переезжает в «подключено» тем же коммитом, которым появляется его первое
настоящее использование, и с именем того, кто его завёл. Пока он в «предложено» — на него
нельзя ссылаться как на существующую гарантию ни в ревью, ни на защите.

**Подключено:** pgx, Gin, goose, golangci-lint (+ depguard/forbidigo — правила описаны,
но пока не матчат ни одного файла), Prism (`make dev`), `testing/synctest` (стандартная
библиотека Go 1.25, отдельно ставить нечего).

**Предложено, ещё не подключено, владельца нет:** oapi-codegen, kin-openapi,
`@rtk-query/codegen-openapi`, sqlc, testcontainers, rapid, `go test -fuzz`,
santhosh-tekuri/jsonschema, coder/websocket, Playwright. Ни одно из них ещё не написано
ни строчкой — это кандидаты, а не решения, независимо от того, что каждое описано ниже
подробно.

**Порядок доверия:** компилятор/кодоген > CI-гейт > рантайм-валидация > ревью агентом >
проза здесь.

## Контракт — ошибка компиляции, а не находка ревью

- **oapi-codegen** (`github.com/oapi-codegen/oapi-codegen/v2` — путь сменился с `deepmap/`)
  генерирует Go-интерфейсы и типы из `docs/openapi.json`. Переименовал поле, не тронув
  спеку — не скомпилируется.
- **kin-openapi** (`github.com/getkin/kin-openapi`) как middleware — второй, независимый
  чек в рантайме: ловит то, что компилируется, но нарушает enum/required/format.
- **`@rtk-query/codegen-openapi`** — то же на фронте: типизированные хуки RTK Query из той
  же спеки, без ручного дублирования типов.

## Гонка на claim награды — протестирована, а не заявлена

- `go test -race` — обязательный шаг CI, не опция.
- **testcontainers-go** — тест идемпотентности и UNIQUE-constraint'а против настоящего
  Postgres, не мока. Это делает «один грант, тест зелёный» проверяемым.

## SQL — читаемый, без магии ORM

- **sqlc** — пишешь ledger/claim-запросы обычным SQL, получаешь типизированные биндинги.
  Осознанно не gorm/ent: ORM прячет именно тот SQL, который на claim-пути надо читать
  построчно.
- **pgx** (`jackc/pgx`) — драйвер, **goose** — миграции (уже используется в `feat/auth`).

## Время — главный источник багов в этом проекте

Практика важнее библиотек: время — параметр, а не `time.Now()` внутри. `decay(state,
from, to)`, а не `decay(state)`. Без этого не спасёт ни одна из следующих:

- **`testing/synctest`** (стандартная библиотека, стабилен с Go 1.25) — там, где время
  параметром не сделать: WS-хартбиты, таймауты реконнекта, ретраи, истечение грантов.
  `synctest.Test`: время двигается мгновенно, когда все горутины заблокированы. `-race`
  не отменяет — synctest делает время детерминированным, гонки не ловит.
- **rapid** (`pgregory.net/rapid`) — property-тесты поверх табличных: «энергия не уходит
  в минус», «уровень не убывает при неотрицательном приросте».
- **`go test -fuzz`** (нативный) — парсер входящих событий `/v1/events` и парсер
  JSONB-конфига правил.
- **santhosh-tekuri/jsonschema** — валидация JSONB-конфига квестов/наград при записи.

## Архитектура — линтер, а не договорённость

- **depguard** (в golangci-lint) — слоевые правила: `service.go` не импортирует
  `net/http`/Gin, БД только из `repo.go`, `pkg/` не импортирует `internal/**`.
- **forbidigo** — `time.Now()` вне `pkg/` и `cmd/`.
- **exhaustive** — забытый `case` в switch по статусным enum'ам.
- Остальные явно: `errcheck`, `sqlclosecheck`, `rowserrcheck`, `gosec`, `bodyclose`,
  `errorlint`, `gocritic`, `durationcheck`, `staticcheck`, `govulncheck`.

## WebSocket

**coder/websocket** (`github.com/coder/websocket`, продолжение `nhooyr/websocket`), не
gorilla: синхронизация конкурентных записей в одно соединение и обработка битых
фреймов/паник встроены, а не на совести автора хаба.

На фронте состояние из WS вливается в кэш RTK Query через `onCacheEntryAdded` на запросе
питомца — отдельный слайс даст сокет, обновляющий себя, пока кэш отдаёт устаревшее
состояние.

## Агентный воркфлоу

**Хуки** — детерминированные гарантии (исполняет харнесс, не модель); **скиллы** —
процедурное знание по релевантности; **сабагенты** — параллельные подразговоры со своим
контекстом.

- `.claude/settings.json` — PreToolUse-гард (force-push, `reset --hard`, `DROP TABLE`),
  PostToolUse-`gofmt`, Stop-хук, не дающий закончить ход с красной сборкой.
- `.claude/commands/{plan,implement,verify,review}.md`.
- `.claude/agents/contract-reviewer.md` — ревью того, что компилятор не ловит.
- `.githooks/pre-push` — гейт для человека; Claude-хуки связывают только агента.
- CI на PR — единственный гейт, который видит всех четверых.

Устаревание API библиотек (Chakra v3, мажоры Gin, sqlc) — самый частый класс ошибок в
этом проекте. Где есть docs-MCP (Context7) или официальные AI-скиллы (Chakra, Redux
Toolkit) — использовать их вместо памяти модели.
