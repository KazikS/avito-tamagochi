name: review

---

Отревьюй текущий дифф против `origin/main` перед PR.

```
git diff origin/main...HEAD
```

Проверь то, что не ловит компилятор и не ловит линтер:

1. **Контракт.** Изменения формы запроса/ответа отражены в `docs/openapi.json`? Коды
   ответов соответствуют смыслу (состояние — 409, не 403)?
2. **Анти-абьюз.** Выдача награды в транзакции? Есть UNIQUE? Награда не превратилась
   в пересылаемую строку?
3. **`source`.** Не теряется на пути `event_inbox` → `energy_ledger`?
4. **Слои.** Импорты соответствуют `docs/ARCHITECTURE.md`? Если линтер молчит, но слой
   размыт логически (например, доменное решение переехало в `repo.go`) — скажи.
5. **Чужая территория.** Дифф трогает чужой пакет или общий файл? Это должно быть
   в описании PR.
6. **Мёртвый код и костыли.** Рубрика оценивает это прямо.

Выведи список находок. Ничего не чини в этом шаге.
