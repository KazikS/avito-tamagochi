# Авито Тамагочи

Go-бэкенд + React-фронт. Хакатон, ~7 дней, greenfield. Один репозиторий, четыре человека.

## Ground truth

`docs/openapi.json` — контракт. Меняешь форму запроса/ответа → правь спеку в том же диффе
и регенерируй (`make gen`). Типы руками не пиши — ни в Go, ни в TypeScript.

## Никогда

- Не начисляй прогресс за действие без реального события Авито *(вопрос пока открыт — `docs/DECISIONS.md`; уперся — остановись, не выбирай сторону сам)*.
- Не выдавай награду строкой-кодом, которую можно переслать.
- Не теряй `source: gamified|organic` между `event_inbox` и `energy_ledger`.
- Не обнуляй прогресс пользователя миграцией.
- Не рисуй знак Авито (4 круга) как персонажа.
- Не вызывай `time.Now()` внутри доменной логики — передавай время параметром.
- Не создавай интерфейс, пока нет второй реальной реализации.
- Не пиши код в `internal/<tag>/service.go`, зависящий от `net/http` или Gin.
- Не ходи в БД из `handler.go` или `service.go` — только через `repo.go`.

## Всегда

- Простейший код, решающий именно запрошенное. Никаких абстракций «на будущее».
- Переформулируй расплывчатую задачу в проверяемые критерии до начала.
- Трогаешь чужой пакет, `docs/openapi.json` или таблицы `event_inbox` / `energy_ledger` /
  `reward_grants` — скажи об этом первой строкой ответа.
- Показывай вывод команд, а не пересказ. Статус «passed» — не результат, результат — вывод.
- Заметил проблему рядом с задачей — назови её в ответе, не чини молча.
- Пиши коммиты со своего аккаунта, Conventional Commits: `feat(rewards): ...`.

## Стоп-вопросы

Список — `docs/DECISIONS.md`, раздел «Открытое». Наткнулся на любой — остановись и спроси.
Раздел «Реконсиляция веток» в том же файле — не открытые вопросы, а известные проблемы в
`feat/auth`/`feat/pet-service`, чинить их без дополнительного согласования можно.
Всё остальное решай сам, не спрашивая.

## Layout

Разбор и обоснование — `docs/ARCHITECTURE.md`. Коротко (целевое состояние — на
`feat/auth`/`feat/pet-service` пока другая раскладка, см. `docs/DECISIONS.md`):

```
backend/cmd/main.go                точка входа, только wiring
backend/internal/<tag>/            один пакет на тег OpenAPI: pet, tasks, streak, rewards, social
        ├── handler.go             HTTP, реализует сгенерированный интерфейс
        ├── service.go             доменная логика, чистые функции, время параметром
        └── repo.go                SQL (sqlc), единственное место с БД
backend/pkg/                       postgres, позже ws, ingest — общее, ниже всех фич
```

Границы пакетов = границы контракта. Слоевые правила проверяет `depguard` в `.golangci.yaml`,
а не ревью.

## Воркфлоу

`/plan` → `/implement` → `/verify` → `/review` перед PR. `/verify` не пропускать.
Несколько агентов на репозитории — каждый в своём git worktree, PR маленькие.

`make` — единственная точка входа для команд: `make test`, `make lint`, `make verify`,
`make gen`, `make seed`, `make e2e`. Не собирай флаги по памяти.

## Библиотеки

Версии API у Gin, sqlc, pgx, coder/websocket и Chakra UI меняются между мажорами.
Не пиши по памяти — сверяйся с документацией установленной версии перед использованием
незнакомого API.
